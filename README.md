# New tab next to active tab
Zen/Sine mod: opens new tabs right after the active (or opener) tab, now also work with split view. 
Essentially adds on top of "insertAfterCurrent" flag in about:config (needs to be on)

#Tab group live renaming
Adds to Advanced Tabs Group by VertexMods, to simulate Vivaldi's tab stack, rename the group to the last used tab in said group.
